Overview

This class is abstract.

Subclass and implement #format_messages and #parse_response

Base adapter interface for LLM providers

Adapters handle provider-specific message formatting and response parsing. Each provider (Anthropic, OpenAI, Gemini) has different API conventions that the adapter normalizes.

Direct Known Subclasses

Anthropic, Gemini, OpenAI

def format_tool_choice(choice)
  case choice.to_s
  when "auto" then "auto"
  when "any" then "required"
  else { type: "function", function: { name: choice.to_s } }
  end
end
