Overview

Represents a tool/function definition for tool calls

Examples:

ToolMessage.new(
  id: "call_123",
  name: "get_weather",
  input: { location: "Berlin" }
)

def self.from_hash(hash)
  hash = hash.transform_keys(&:to_sym)
  new(
    id: hash[:id],
    name: hash[:name],
    input: hash[:input] || hash[:arguments] || {}
  )
end
